# Open City C++ (`open-city-cpp`) — v0.6.0

실제 GTA 시리즈처럼 **모던 C++20**과 **OpenGL 3.3 (`raylib 5.5` + 커스텀 GLSL 셰이더)** 기반으로 제작된 **3D 1인칭·3인칭 오픈월드 시티 액션 & 경제 샌드박스 게임**입니다.

별도의 외부 에셋 폴더나 런타임(VC++ 재배포 패키지) 설치 없이 **단일 `open_city.exe` 실행 파일 하나만으로** Windows 10/11에서 즉시 실행되며, Windows 기본 한글 폰트(`맑은 고딕`)를 통해 현대 한글 11,172자 전체를 깨짐 없이 렌더링합니다.

---

## 바로 플레이하기 (Windows `.exe` 다운로드)

컴파일러 설치 없이 바로 플레이하려면 GitHub 자동 빌드 결과물을 내려받으세요:

1. 리포지토리 우측 **[Releases](https://github.com/stickmongus/open-city-cpp/releases)** 페이지로 이동합니다.
2. 최신 버전(**`v0.6.0`**)의 **`OpenCity-Windows-x64.zip`** 파일을 다운로드하고 압축을 풉니다.
3. **`open_city.exe`** 를 더블클릭하면 바로 게임이 시작됩니다!

## 주요 기능 (v0.6.0 업데이트)

* **어지러움 제로(`Zero-Dizziness`) 1:1 정밀 에임 & 카메라 안정화**
  * 좌우(`Yaw`)·상하(`Pitch`) 마우스 회전 지연을 완전히 없앤 **0ms 1:1 동기화 에임** 적용 + 보행 인도 턱 높낮이만 부드럽게 감쇠해 카메라 멀미 원천 차단
  * 우클릭(`RMB`) 정밀조준 시 어깨 축 흔들림과 급격한 시야각 변화(돌리 줌 현상)를 제거하고, **우클릭 시 자동 감도 감속(`0.58x`)** 및 **`[` / `]` 키 실시간 마우스 감도 조절(`30% ~ 250%`)** 지원
  * 발사 시 번쩍이며 튀던 조준선 확장을 제거해 장시간 교전에도 눈이 편안한 고정밀 레티클 & 향상된 정밀 집탄율 제공
* **`[V]` (또는 마우스 휠클릭) 완전한 1인칭 시점 (`도보 FPS + 3D 차량 운전석`)**
  * **1인칭 도보 FPS 모드**: 수평선 흔들림(Head-Bob) 제로 설계 + 현재 착용 의상 소매가 반영된 **무기 7종 전용 3D 뷰모델** 탑재! 우클릭 시 권총 트리튬 가늠쇠, SMG 시안 리플렉스, 소총 레드닷 홀로그램, 중기관총 그린 도트 조준기가 화면 정중앙에 **정축(Co-Axial) 광학 정렬**
  * **1인칭 차량 운전석(Cockpit) 모드**: 전 차량 10종 좌핸들 운전석 시야, 조향에 따라 **실시간 회전하는 3D 스포츠 스티어링 휠 & 양손**, 디지털 속도·RPM 게이지, 경찰차 전술 단말기(`MDT`), 차종별 유선형 보닛(머슬카 V8 슈퍼차저 스쿱·경찰 푸시범퍼 포함) 렌더링
* **3D 도보 점프 (`Space`), 시민 비명·만세 도주 AI & 경찰 1~5성(`★1~★5`) 추격전**
  * 도보 **`Space`** 점프 및 차량 지붕·화물 상자 등반 파쿠르 액션
  * 총기 조준·총성·폭발·차량 탈취·인도 질주 시 주변 시민들이 비명과 함께 **두 팔을 들고 방사형으로 전력 질주 도주**
  * **`SBPD 경찰 추격차`**(레드·블루 스트로브 경광등 & 사이렌) 및 `★4~★5` **SWAT 방탄 SUV** 출동, `PAY 'N' TUNE` 도색 위장 및 스마트폰 브로커 수배 해제 지원
* **32-스테이션 곡면 스컬프팅 3D 차량 10종 & 오픈월드 경제·시네마틱 그래픽**
  * **`LUXURY AUTOS` 슈퍼카 전시장**, **부동산 6곳 자동 배당 수익**, **`PAY 'N' TUNE` 풀튜닝 & LED 네온 언더글로우**, **`MODA` 의상 부티크**
  * 2048x2048 실시간 태양/달 소프트 그림자(PCF), 절차적 하늘·구름·파도 셰이더, 멀티링 HDR 블룸 & ACES 톤매핑 (`[F3]` 그래픽 품질 전환)

## 조작키 안내

| 입력 | 동작 |
| :--- | :--- |
| `W` `A` `S` `D` / 방향키 | 도보 이동 / 차량 가속·후진·조향 |
| **`V` 또는 마우스 휠클릭 (`MMB`)** | **1인칭 시점 (도보 FPS · 3D 차량 운전석) ↔ 3인칭 시점 즉시 전환** |
| 마우스 이동 | 흔들림 없는 1:1 정밀 시점 조준 (`-64°` 하단 ~ `+68°` 상단) |
| 마우스 우클릭 (`RMB`) / 좌클릭 (`LMB`) | **정밀 광학 조준 (자동 감도 감속)** / 무기 발사 |
| **`[` / `]`** | **실시간 마우스 감도 낮추기 / 높이기 (`30% ~ 250%`)** |
| `Space` | **도보 3D 점프 (차량 지붕 등반)** / 차량 핸드브레이크 **드리프트** |
| `F` 또는 `E` | 차량 탑승·주행 차량 탈취·하차 / 미션 마커에서 미션 시작 |
| `P` | **스마트폰 열기/닫기** (`Q`/`E` 탭 전환, `1`~`7` 슈퍼카 호출·부동산·보급·**경찰 수배 해제**) |
| `B` | 상점·전시장·풀튜닝 차고(도색 수배 해제)·주유소·부티크 메뉴 열기 (`1`~`8` 선택) |
| `Left Shift` | 도보 전력질주 / 차량 **니트로 부스트** |
| `1` ~ `7` / 마우스 휠 | 무기 슬롯 교체 (권총·SMG·샷건·소총·중기관총·폭발 런처) |
| `R` | 탄창 재장전 |
| `G` | 차량 경적 울리기 / **경찰차 사이렌 & 경광등 ON/OFF** |
| `C` | 후방 카메라 보기 |
| `I` | 마우스 상하(Y축) 시점 반전 토글 |
| `F3` | 그래픽 품질 프리셋 전환 (`울트라` / `높음` / `고성능`) |
| `T` | 시간 빠르게 감기 (+3시간, 낮/노을/밤 즉시 전환) |
| `L` | 한국어 / 영어 UI 전환 |
| `H` | 좌측 상단 조작 안내 표시/숨기기 |
| `Tab` / `ESC` | 메뉴 닫기 / 마우스 커서 잠금·해제 |
| `Backspace` | 진행 중인 미션 중단 |
| `F11` | 전체화면 전환 |

## 소스 코드에서 직접 빌드하기 (CMake + C++20)

`raylib 5.5`는 CMake `FetchContent`를 통해 자동으로 다운로드·정적 링크됩니다.

### Windows (Visual Studio 2022 + CMake)
```powershell
cmake -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release --parallel
.\build\Release\open_city.exe
```

### Linux (Debian / Ubuntu)
```bash
sudo apt-get install build-essential cmake ninja-build \
  libgl1-mesa-dev libx11-dev libxrandr-dev libxi-dev libxcursor-dev libxinerama-dev
cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
ctest --test-dir build --output-on-failure
./build/open_city
```
