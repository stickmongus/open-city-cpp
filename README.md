# Open City C++ (`open-city-cpp`) — v0.7.0

실제 GTA 시리즈처럼 **모던 C++20**과 **OpenGL 3.3 (`raylib 5.5` + 커스텀 GLSL 셰이더)** 기반으로 제작된 **3D 1인칭·3인칭 오픈월드 시티 액션 & 경제 샌드박스 게임**입니다.

별도의 외부 에셋 폴더나 런타임(VC++ 재배포 패키지) 설치 없이 **단일 `open_city.exe` 실행 파일 하나만으로** Windows 10/11에서 즉시 실행되며, Windows 기본 한글 폰트(`맑은 고딕`)를 통해 현대 한글 11,172자 전체를 깨짐 없이 렌더링합니다.

---

## 바로 플레이하기 (Windows `.exe` 다운로드)

컴파일러 설치 없이 바로 플레이하려면 GitHub 자동 빌드 결과물을 내려받으세요:

1. 리포지토리 우측 **[Releases](https://github.com/stickmongus/open-city-cpp/releases)** 페이지로 이동합니다.
2. 최신 버전(**`v0.7.0`**)의 **`OpenCity-Windows-x64.zip`** 파일을 다운로드하고 압축을 풉니다.
3. **`open_city.exe`** 를 더블클릭하면 바로 게임이 시작됩니다!

## 주요 기능 (v0.7.0 업데이트)

* **총기·중화기 11종 풀 아스날 & 3.2배율 광학 저격 스코프 (`1인칭·3인칭 3D 모델 + 전용 사운드`)**
  * 기본 무장(`맨주먹`, `9mm 권총`, `전술 기관단총`, `펌프 샷건`, `돌격 카빈소총`, `컴뱃 중기관총`, `전술 폭발 런처`)에 더해 **신규 화기 4종** 대폭 확충!
  * **`44 매그넘 리볼버`**: 브러시드 크롬 6연발 대구경 핸드캐논 (`피해량 88`, `AMMU-TECH [9]`)
  * **`전자동 드럼 샷건`**: 16발 드럼탄창 12게이지 연사 샷건 (`6펠릿 × 18`, `AMMU-TECH [0]` / 스마트폰 보급 `[8]`)
  * **`전술 저격소총`**: `195m` 초장거리 정밀 저격소총 — 우클릭(`RMB`) 시 **`24°` 3.2배율 일루미네이티드 밀닷(Mil-Dot) 광학 스코프 + 실시간 레이저 거리측정기(`RNG`) HUD** 및 정밀 저속 감도(`0.28x`) 작동 (`AMMU-TECH [-]` / 스마트폰 보급 `[9]`)
  * **`6열 개틀링 미니건`**: 200발 대용량 드럼·초당 24발급 초고속 화력 — 조준·사격 시 **1·3인칭 6열 회전 총열이 실시간 스핀업** (`AMMU-TECH [=]` / 스마트폰 보급 `[0]`)
* **32-스테이션 곡면 스컬프팅 3D 차량 16종 풀 라인업 (`전시장 10종 + 긴급·특수차량`)**
  * **`샌드킹 4x4 픽업트럭`** (오목한 리얼 적재함·불바·루프 4연장 LED 서치라이트), **`코케트 오픈 로드스터`** (오픈탑 가죽 버킷시트·크롬 롤후프·하늘이 열린 1인칭 운전석), **`설탄 RS 드리프트 튜너`** (전면 노출 인터쿨러 `FMIC`·루프 스쿱·드리프트 특화), **`발키리 LMP 트랙카`** (도살 샤크핀·초고속 `207+ km/h` 르망 프로토타입)
  * **`선셋베이 119 구급차`** (적십자 엠블럼·레드/화이트 경광등·탑승 시 **체력 `+35 HP` 구급키트 회복**) & **`선셋베이 중형 소방차`** (루프 알루미늄 사다리 랙·측면 셔터·레드/앰버 경광등, `[G]` 키 사이렌 지원)
* **어지러움 제로(`Zero-Dizziness`) 1:1 정밀 에임 & `[V]` 1인칭(FPS·운전석) / 3인칭 시점**
  * 0ms 1:1 마우스 동기화 에임, 우클릭 자동 감도 감속, `[` / `]` 실시간 감도 조절(`30% ~ 250%`), 16종 전 차량 1인칭 실시간 스티어링 휠 & 디지털 계기판
* **3D 도보 점프 (`Space`), 시민 비명·만세 도주 AI, 경찰 `★1~★5` 추격전 & 오픈월드 경제**
  * `LUXURY AUTOS` 슈퍼카 전시장, 부동산 6곳 배당 수익, `PAY 'N' TUNE` 풀튜닝·네온·수배 위장, 2048px 소프트 그림자 & HDR 블룸/ACES 톤매핑 (`[F3]` 품질 전환)

| 입력 | 동작 |
| :--- | :--- |

| **`1` ~ `9`, `0`, `-` / `Z`·`X` / 마우스 휠** | **무기 11종 슬롯 즉시 선택 및 이전(`Z`)·다음(`X`) 순환 교체** |

| `Space` | **도보 3D 점프 (차량 지붕 등반)** / 차량 핸드브레이크 **드리프트** |
| `F` 또는 `E` | 차량 탑승·주행 차량 탈취·하차 / 미션 마커에서 미션 시작 |
| `P` | **스마트폰 열기/닫기** (`Q`/`E` 탭 전환, `1`~`9`,`0` 차량 10종 호출·부동산·중화기 보급·**수배 해제**) |
| `B` | 상점·전시장·풀튜닝 차고·주유소·부티크 메뉴 열기 (`1`~`9`, `0`, `-`, `=` 선택) |
| `Left Shift` | 도보 전력질주 / 차량 **니트로 부스트** |
| `R` | 탄창 재장전 |
| `G` | 차량 경적 울리기 / **경찰차·구급차·소방차 사이렌 & 경광등 ON/OFF** |

| `F3` | 그래픽 품질 프리셋 전환 (`울트라` / `높음` / `고성능`) |

## 소스 코드에서 직접 빌드하기 (CMake + C++20)

`raylib 5.5`는 CMake `FetchContent`를 통해 자동으로 다운로드·정적 링크됩니다.

### Windows (Visual Studio 2022 + CMake)
```powershell
cmake -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release --parallel
.\build\Release\open_city.exe
```

### Linux (Debian / Ubuntu)
```bash
sudo apt-get install build-essential cmake ninja-build \
  libgl1-mesa-dev libx11-dev libxrandr-dev libxi-dev libxcursor-dev libxinerama-dev
cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
ctest --test-dir build --output-on-failure
./build/open_city
```
