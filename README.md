# Open City C++ (`open-city-cpp`) — v0.5.0

실제 GTA 시리즈처럼 **모던 C++20**과 **OpenGL 3.3 (`raylib 5.5` + 커스텀 GLSL 셰이더)** 기반으로 제작된 **3D 3인칭 오픈월드 시티 액션 & 경제 샌드박스 게임**입니다.

별도의 외부 에셋 폴더나 런타임(VC++ 재배포 패키지) 설치 없이 **단일 `open_city.exe` 실행 파일 하나만으로** Windows 10/11에서 즉시 실행되며, Windows 기본 한글 폰트(`맑은 고딕`)를 통해 현대 한글 11,172자 전체를 깨짐 없이 렌더링합니다.

---

## 바로 플레이하기 (Windows `.exe` 다운로드)

컴파일러 설치 없이 바로 플레이하려면 GitHub 자동 빌드 결과물을 내려받으세요:

1. 리포지토리 우측 **[Releases](https://github.com/stickmongus/open-city-cpp/releases)** 페이지로 이동합니다.
2. 최신 버전(**`v0.5.0`**)의 **`OpenCity-Windows-x64.zip`** 파일을 다운로드하고 압축을 풉니다.
3. **`open_city.exe`** 를 더블클릭하면 바로 게임이 시작됩니다!

## 주요 기능 (v0.5.0 업데이트)

* **3D 도보 점프 (`Space`) & 차량 루프 파쿠르 액션**
  * 도보 상태에서 **`Space`** 키로 중력·체공 포즈·지면 밀착 그림자가 적용된 **입체 3D 점프** 지원
  * 주차되거나 서행 중인 승용차·SUV·경찰차 지붕, 화물 상자, 벤치 위로 직접 뛰어올라 **차량 지붕 위 고지대 사격 및 파쿠르 이동** 가능
* **생동감 넘치는 시민 비명·만세 도주 AI & 패닉 운전자**
  * 총기 조준, 총성·폭발, 근접 공격, 차량 탈취, 인도 질주, 경찰 사이렌 발생 시 주변 시민들이 비명을 지르며 **두 팔을 머리 위로 흔들며 방사형으로 전력 질주 도주** (위험이 사라지면 안전하게 인도로 복귀)
  * 위협을 감지한 주변 차량 운전자들도 급가속으로 현장을 이탈하는 패닉 주행 반응 탑재
* **선셋베이 경찰청 (`SBPD`) & 1~5성 수배 (`★1~★5`) 추격 시스템**
  * 신규 10번째 유선형 3D 차량 **`선셋베이 경찰 추격차 (SBPD INTERCEPTOR)`** 추가: 블랙 & 화이트 도장, 강철 푸시 범퍼, A필러 서치라이트, **루프 레드 & 블루 LED 경광등 스트로브** 및 지면 반사광, 거리 감쇠 경찰 사이렌 사운드 구현 (경찰차 탈취 후 `[G]` 키로 직접 사이렌 ON/OFF 가능!)
  * 범죄 수위에 따라 **`★1 ~ ★5` 수배 단계** 상승: 일반 순찰 경관(`★1~★3`)부터 방탄 헬멧·전술 조끼·소총/중기관총으로 무장한 **SWAT 특수기동대 방탄 SUV(`★4~★5`)** 까지 다중 추격 전개
  * **수배 해제 & 체포(`BUSTED`) 시스템**: 경찰 시야 이탈 도주 게이지 완주, **`PAY 'N' TUNE`** 차량 수리·도색 위장, 또는 **스마트폰(`[P]`) 긴급보급 탭 `[7]` 경찰 수배 즉시 해제 브로커** 지원 (경찰 근처에서 제압 시 다운타운 경찰서 앞으로 체포 리스폰)
* **32-스테이션 곡면 스컬프팅 3D 차량 모델링 (총 10종) & 오픈월드 경제**
  * 박스/레고 형태를 탈피한 유선형 3D 차체 로프팅 메쉬 + 오목 5-트윈 스포크 단조 휠 + 입체 필러 유리창 (`젠토르노 X` 하이퍼카, `인서전트 VIP` 방탄 SUV, `SBPD 경찰 추격차` 등 총 10종)
  * **`LUXURY AUTOS` 슈퍼카 전시장**, **부동산·사업장 6곳 매입(25초마다 자동 배당 수익)**, **`PAY 'N' TUNE` 풀튜닝 & 하부 LED 네온 언더글로우**, **`MODA` 의상 부티크**, **`컴뱃 중기관총` & `전술 폭발 런처`** 완비
* **사실적인 3D 해안 메트로폴리스 & 시네마틱 그래픽**
  * 1층 상가 쇼윈도·어닝·발코니·헬리패드, `GLOBE OIL` 주유소, `PULSE` 나이트클럽, 서쪽 백사장 해변 및 **선셋 베이 우드 오션 피어**
  * 2048x2048 실시간 태양/달 소프트 그림자(PCF), 절차적 하늘·구름·파도 셰이더, 멀티링 HDR 블룸 & ACES 톤매핑 (`[V]` 키 그래픽 프리셋 전환)

## 조작키 안내

| 입력 | 동작 |
| :--- | :--- |
| `W` `A` `S` `D` / 방향키 | 도보 이동 / 차량 가속·후진·조향 |
| 마우스 이동 | 상하좌우 자유 3인칭 시점 회전 (`-64°` 하단 ~ `+68°` 고층빌딩·하늘 상단) |
| 마우스 우클릭 (`RMB`) / 좌클릭 (`LMB`) | 정밀 줌 조준 / 무기 발사 |
| `Space` | **도보 3D 점프 (차량 지붕 등반)** / 차량 핸드브레이크 **드리프트** |
| `F` 또는 `E` | 차량 탑승·주행 차량 탈취·하차 / 미션 마커에서 미션 시작 |
| `P` | **스마트폰 열기/닫기** (`Q`/`E` 탭 전환, `1`~`7` 슈퍼카 호출·부동산·보급·**경찰 수배 해제**) |
| `B` | 상점·전시장·풀튜닝 차고(도색 수배 해제)·주유소·부티크 메뉴 열기 (`1`~`8` 선택) |
| `Left Shift` | 도보 전력질주 / 차량 **니트로 부스트** |
| `1` ~ `7` / 마우스 휠 | 무기 슬롯 교체 (권총·SMG·샷건·소총·중기관총·폭발 런처) |
| `R` | 탄창 재장전 |
| `G` | 차량 경적 울리기 / **경찰차 사이렌 & 경광등 ON/OFF** |
| `C` | 후방 카메라 보기 |
| `I` | 마우스 상하(Y축) 시점 반전 토글 |
| `V` | 그래픽 품질 프리셋 전환 (`울트라` / `높음` / `고성능`) |
| `T` | 시간 빠르게 감기 (+3시간, 낮/노을/밤 즉시 전환) |
| `L` | 한국어 / 영어 UI 전환 |
| `H` | 좌측 상단 조작 안내 표시/숨기기 |
| `Tab` / `ESC` | 메뉴 닫기 / 마우스 커서 잠금·해제 |
| `Backspace` | 진행 중인 미션 중단 |
| `F11` | 전체화면 전환 |

## 소스 코드에서 직접 빌드하기 (CMake + C++20)

`raylib 5.5`는 CMake `FetchContent`를 통해 자동으로 다운로드·정적 링크됩니다.

### Windows (Visual Studio 2022 + CMake)
```powershell
cmake -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release --parallel
.\build\Release\open_city.exe
```

### Linux (Debian / Ubuntu)
```bash
sudo apt-get install build-essential cmake ninja-build \
  libgl1-mesa-dev libx11-dev libxrandr-dev libxi-dev libxcursor-dev libxinerama-dev
cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
ctest --test-dir build --output-on-failure
./build/open_city
```
