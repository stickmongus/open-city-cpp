# Open City Seoul — Native Vulkan (`open-city-cpp`) v6.1.0

실제 AAA 오픈월드처럼 **모던 C++20 + Native Vulkan 1.0+ 렌더링 엔진 (volk · SPIR-V 1.0 · 카메라 상대 고정밀 뎁스 · DPI 독립 반응형 모바일 HUD · 16-bit HDR + 4× MSAA + 2048px Soft PCF 그림자 + 듀얼 4096×4096 8× 이방성 밉맵 건축/도로 PBR 아틀라스 + 4096×4096 64슬롯 4K 한글 간판·이정표 + 3D 인테리어 패럴랙스 매핑 + 실시간 동적 20광원 PBR) + DLR Eclipse SUMO 중심정렬 단일 토폴로지 3D 도로·교차로·보도·건물전면광장 메쉬 엔진 (`OCRM v1`, `assets/maps/seoul_roads_hd.ocrm`, 국토지리정보원 정밀도로지도 NGII HD Map 및 행정안전부 실폭도로 `TL_SPRD_RW` 공식 SHP 임포터 내장!) + 1:1 도로 동기화 Geofabrik OSM · Overture Maps · TUM GlobalBuildingAtlas 186,117채 실제 서울 3D 건물 & AWS Terrarium 15m 베어-어스 DTM 융합 월드 (`OCM6 v4`) + Rust (`#![no_std]` 임계감쇠 서스펜션 물리 커널 v2000)** 아키텍처로 구축된 **크로스플랫폼(Android · Windows · Linux) 실제 지도·단일 토폴로지 정밀도로·실제 건축 기반 서울 3D 오픈월드 대도시 샌드박스 게임**입니다.

- **1:1 도시·건물·시설물·고속도로 완전 동기화 (`v6.1.0`)**: Eclipse SUMO 중심정렬(`--default.spreadtype center`) 단일 토폴로지 도로망(`seoul_roads_hd.ocrm` · `26.64 MB`)과 `seoul_real.ocmap`(`31.92 MB`)을 **1:1로 완전 동기화**했습니다. 최신 **Geofabrik 대한민국 OSM 실측 건물(114,618채)** 을 내려받아 기존 Overture/TUM 3D 건물과 융합(**186,117채 · 109,413채 태그 고도화 · 1,936채 신규 건물 추가**)하고, 도로를 침범하던 **19,321채 건물 폴리곤을 SUMO 도로/교차로 경계 밖으로 수학적 클리핑(도로 침범 0.00%)** 및 보도 고도에 밀착 접지했습니다.
- **건물 전면 6.5m 화강암 광장 & 4m 초정밀 지면 등고선(함몰 웅덩이 0.00%) · 서울 고속도로 전면 정비**: 보도+건물전면 광장(Tile 4 연마 화강암 판석)을 건물 외벽까지 확장하고 `64×64(4m)` 삼각형 거리 기반 지면 등고선을 적용해 상가 앞 지면 함몰/틈새를 완전 제거했습니다. 경부고속도로(10차로 본선)·올림픽대로·강변북로·내부순환로·삼성교×분당수서 다층 입체교차로의 포털 가로막힘 벽·잘못된 교량 분할·교각 하부도로 침범을 전면 정비했습니다.
- **대한민국 공식 정부 정밀도로지도 / 실폭도로 SHP 원클릭 임포터 (`tools/import_korea_hdmap_ocrm.py`)**: 국토지리정보원 정밀도로지도(**NGII HD Map**: `A3_DRIVEWAYSECTION.shp`, `B2_SURFACELINEMARK.shp`, `B3_SURFACEMARK.shp`, `A2_LINK.shp`), 행정안전부 도로명주소 **실폭도로(`TL_SPRD_RW.shp`)**, 1:1000 연속수치지형도(`A001`/`A003`/`A004`)를 좌표계 자동 인식(`EPSG:5179`/`5186`/`5174`/`32652`/`4326`)으로 기존 `seoul_roads_hd.ocrm` 위에 청크 단위 패치할 수 있습니다.
- **Native Vulkan 1.0+ (Zero OpenGL / Zero raylib)**: Android(`arm64-v8a` + `armeabi-v7a`), Windows x64, Linux x64 모두 100% 네이티브 Vulkan 파이프라인으로 구동됩니다.
- **Android (`.apk`)**: 정식 RSA-4096 v1/v2/v3 서명 + 16KB ELF 페이지 정렬된 유니버설 Vulkan APK(`arm64-v8a` + `armeabi-v7a`) 하나로 Android 7.0+ Vulkan 지원 스마트폰·폴더블·태블릿에서 즉시 실행됩니다.
- **Windows (`.exe`)**: 별도 런타임 없이 압축 해제 후 `open_city.exe` 실행 파일 하나로 Windows 10/11(Vulkan 지원 GPU)에서 즉시 실행됩니다.

## 주요 혁신 (v6.1.0 도시·실측 OSM 건물·시설물·고속도로 1:1 SUMO 도로 완전 동기화)

0. **최신 Geofabrik 대한민국 OSM 실측 건물 다운로드·융합 & 1:1 SUMO 도로 클리핑 (`tools/sync_city_and_buildings_to_sumo.py`)**
   * **실측 건물 186,117채 & 도로 침범 0.00%**: 최신 Geofabrik OSM 건물(114,618채)을 기존 Overture/TUM 3D 위성높이 건물과 융합해 층수·지붕형상·외장재·색상·1층 상가 정보를 갱신하고, 모든 건물을 SUMO 도로/교차로 폴리곤 밖으로 수학적 클리핑(**19,321채 정비**) 및 동기화된 보도 고도에 정밀 접지했습니다.
   * **주차 차량·가로등·가드레일·신호등 1:1 정렬**: `seoul_real.ocmap`의 47,669개 3D 도로(751,291 정점)와 6,409개 SUMO 신호교차로가 `seoul_roads_hd.ocrm`과 1:1 일치하여 주차 차량은 최우측 아스팔트 차로 내부에만, 가로등·가드레일·가로수는 화강암 연석 뒤편에만 배치됩니다.
1. **건물 전면 6.5m 화강암 광장(Tile 4) & 4m 삼각형 거리 지면 등고선 (`Renderer3D.cpp` · `world.frag`)**

2. **서울 핵심 고속도로 전면 정비 (경부고속도로 10차로 · 올림픽대로 · 강변북로 · 내부순환로 · 삼성교×분당수서)**
   * 경부고속도로·강남대로·세종대로 차로수 정교화, 저높이 암거교 오분할 차단, 교량 진입/출구 포털 가로막힘 방호벽 완전 제거, 고가교 교각 하부도로 회피, 그리고 다층 입체교차로(분당수서↔삼성교) 높이 분리까지 **39개 자동화 테스트(Release + ASan/UBSan) 100% 통과**!

## 소스 코드에서 직접 빌드하기

### Android `.apk` 직접 빌드 (Linux + Android SDK/NDK + JDK)
```bash
export ANDROID_KEYSTORE_PATH=/path/to/open-city-release.jks
export ANDROID_KEY_ALIAS=opencity
export ANDROID_STORE_PASSWORD="..."
export ANDROID_KEY_PASSWORD="..."

# 유니버설 Native Vulkan APK (arm64-v8a + armeabi-v7a) 빌드·정렬·서명·검증
./tools/build_android_apk.sh
```

### Windows (Visual Studio 2022 + Rust + CMake)
```powershell
cmake -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release --parallel
.\build\Release\open_city.exe
```

### Linux (Debian / Ubuntu)
```bash
sudo apt-get install build-essential cmake ninja-build rustc python3 \
  libx11-dev libxrandr-dev libxi-dev libxcursor-dev libxinerama-dev libvulkan1
cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
ctest --test-dir build --output-on-failure
./build/open_city              # PC Native Vulkan 모드
./build/open_city --mobile-ui  # PC에서 모바일 터치 HUD 미리보기
```
