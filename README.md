# Open City C++ (`open-city-cpp`) — v0.4.0

실제 GTA 시리즈처럼 **모던 C++20**과 **OpenGL 3.3 (`raylib 5.5` + 커스텀 GLSL 셰이더)** 기반으로 제작된 **3D 3인칭 오픈월드 시티 액션 & 경제 샌드박스 게임**입니다.

별도의 외부 에셋 폴더나 런타임(VC++ 재배포 패키지) 설치 없이 **단일 `open_city.exe` 실행 파일 하나만으로** Windows 10/11에서 즉시 실행되며, Windows 기본 한글 폰트(`맑은 고딕`)를 통해 현대 한글 11,172자 전체를 깨짐 없이 렌더링합니다.

---

## 바로 플레이하기 (Windows `.exe` 다운로드)

컴파일러 설치 없이 바로 플레이하려면 GitHub 자동 빌드 결과물을 내려받으세요:

1. 리포지토리 우측 **[Releases](https://github.com/stickmongus/open-city-cpp/releases)** 페이지로 이동합니다.
2. 최신 버전(**`v0.4.0`**)의 **`OpenCity-Windows-x64.zip`** 파일을 다운로드하고 압축을 풉니다.
3. **`open_city.exe`** 를 더블클릭하면 바로 게임이 시작됩니다!

## 주요 기능 (v0.4.0 대규모 업데이트)

* **32-스테이션 곡면 스컬프팅 3D 차량 모델링 (총 9종)**
  * 박스/레고 형태를 완전히 탈피한 **유선형 3D 차체 로프팅 메쉬** + 부드러운 크리즈 법선 보간 + 클리어코트 유광 메탈릭 및 무광 새틴 셰이딩
  * 원형으로 파인 3D 휠하우스 아치, **오목 5-트윈 스포크 단조 알로이 휠**, 레드 스포츠 브레이크 캘리퍼, A/B/C 필러 프레임이 살아있는 입체 유리창 & 파노라마 글래스 루프, 프론트 스플리터·리어 디퓨저 구현
  * 신규 하이퍼카 **젠토르노 X (`ZENTORNO X`)**, **인서전트 VIP 방탄 SUV**, **코그노센티 S 럭셔리 세단**을 포함한 총 9종 차량 수록
* **현금으로 즐기는 오픈월드 경제 · 자산 성장 & 스마트폰 (`[P]`)**
  * **iFRUIT 스마트폰 (`[P]` 키, `[Q]`/`[E]` 탭 전환)**: 언제 어디서나 내 소유 슈퍼카 도로변 즉시 배달 호출, 부동산·사업장 투자, 의상 교체, 긴급 방탄·탄약·중화기 보급 지원
  * **LUXURY AUTOS 프리미엄 슈퍼카 전시장**: 회전 턴테이블 쇼룸에서 차량 6종 영구 구매 및 내 차고 등록
  * **부동산 & 수익 사업장 6곳 매입**: 선셋 비치 콘도, 글로브 오일 주유소, 페이앤튠 본점, 펄스 나이트클럽, 럭셔리 오토 지분, 이클립스 스카이 펜트하우스 인수 시 **25초마다 자동 배당 수익** 지급 + 영구 패시브 특전(`최대 체력·방탄 150`, `니트로 충전 2배`, `튜닝비 50% 할인`, `미션 보상 +25%`)
  * **PAY 'N' TUNE 풀튜닝 공방**: 터보 엔진 스테이지 Lv 1~3, 방탄 차체·타이어 Lv 1~3, **하부 LED 네온 언더글로우 (5색)**, 카본 GT 에어로 스포일러 장착/탈거, 단조 휠 컬러(실버/골드/블랙), 메탈릭·무광 새틴 도색 (개인 차고에 영구 저장)
  * **MODA 의상 부티크 & 중화기 해금**: 피격 데미지를 줄여주는 3D 캐릭터 의상 6종(`바이스 화이트 수트`, `특수부대 전술 방탄복`, `VIP 골드 보스 코트` 등)과 대용량 **`컴뱃 중기관총`**, 광역 폭파 **`전술 폭발 런처`** 추가
* **살아 숨쉬는 사실적인 3D 해안 메트로폴리스 (`Sunset Bay`)**
  * 1층 상가 쇼윈도·출입문·어닝(차양), 아파트 입체 발코니·난간, 펜트하우스 옥상 헬리패드(`H`), 차량이 그대로 통과하며 급속 주유·정비하는 **`GLOBE OIL` 주유소**, 야간 서치라이트와 이퀄라이저 네온이 빛나는 **`PULSE` 나이트클럽**
  * 서쪽 해안선을 따라 펼쳐진 **선셋 백사장 해변**, 인명구조대 타워, 파라솔·선베드, 바다 위를 직접 달리거나 걸을 수 있는 **선셋 베이 우드 오션 피어(부두)**, 유리 버스정류장·가로수 화단·벤치·옥외 광고판 구현
* **GTA V 스타일 시네마틱 그래픽 & 정밀 3D 전투/AI**
  * 2048x2048 실시간 태양/달 소프트 그림자(PCF), 절차적 대기 산란 하늘 돔 & 해안 파도 셰이더, 멀티링 HDR 블룸(Bloom) & ACES 톤매핑 (`[V]` 키 그래픽 프리셋 실시간 전환)
  * 화면 중앙 광학 레이캐스트 기반 정밀 3D 사격(헤드샷 크리티컬 & 히트마커), 신호등과 횡단보도를 지키는 도시 차량·보행자 AI, 반복 플레이 가능한 3종 미션

## 조작키 안내

| 입력 | 동작 |
| :--- | :--- |
| `W` `A` `S` `D` / 방향키 | 도보 이동 / 차량 가속·후진·조향 |
| 마우스 이동 | 상하좌우 자유 3인칭 시점 회전 (`-64°` 하단 ~ `+68°` 고층빌딩·하늘 상단) |
| 마우스 우클릭 (`RMB`) / 좌클릭 (`LMB`) | 정밀 줌 조준 / 무기 발사 |
| `F` 또는 `E` | 차량 탑승·주행 차량 탈취·하차 / 미션 마커에서 미션 시작 |
| `P` | **스마트폰 열기/닫기** (`Q`/`E` 앱 전환, `1`~`6` 슈퍼카 호출·부동산·의상·보급) |
| `B` | 상점·전시장·풀튜닝 차고·주유소·부티크 구역 안에서 메뉴 열기 (`1`~`8` 선택) |
| `Space` | 차량 핸드브레이크 **드리프트** |
| `Left Shift` | 도보 전력질주 / 차량 **니트로 부스트** |
| `1` ~ `7` / 마우스 휠 | 무기 슬롯 교체 (권총·SMG·샷건·소총·중기관총·폭발 런처) |
| `R` | 탄창 재장전 |
| `G` | 차량 경적 울리기 |
| `C` | 후방 카메라 보기 |
| `I` | 마우스 상하(Y축) 시점 반전 토글 |
| `V` | 그래픽 품질 프리셋 전환 (`울트라` / `높음` / `고성능`) |

| `F11` | 전체화면 전환 |

## 소스 코드에서 직접 빌드하기 (CMake + C++20)

`raylib 5.5`는 CMake `FetchContent`를 통해 자동으로 다운로드·정적 링크됩니다.

### Windows (Visual Studio 2022 + CMake)
```powershell
cmake -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release --parallel
.\build\Release\open_city.exe
```

### Linux (Debian / Ubuntu)
```bash
sudo apt-get install build-essential cmake ninja-build \
  libgl1-mesa-dev libx11-dev libxrandr-dev libxi-dev libxcursor-dev libxinerama-dev
cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
ctest --test-dir build --output-on-failure
./build/open_city
```
