# Open City C++ (`open-city-cpp`) — v0.8.0

실제 GTA 시리즈처럼 **모던 C++20**과 **OpenGL 3.3 (`raylib 5.5` + 커스텀 GLSL 셰이더)** 기반으로 제작된 **3D 1인칭·3인칭 오픈월드 시티 액션 & 풀 커스터마이징 샌드박스 게임**입니다.

별도의 외부 에셋 폴더나 런타임(VC++ 재배포 패키지) 설치 없이 **단일 `open_city.exe` 실행 파일 하나만으로** Windows 10/11에서 즉시 실행되며, Windows 기본 한글 폰트(`맑은 고딕`)를 통해 현대 한글 11,172자 전체를 깨짐 없이 렌더링합니다.

---

## 바로 플레이하기 (Windows `.exe` 다운로드)

컴파일러 설치 없이 바로 플레이하려면 GitHub 자동 빌드 결과물을 내려받으세요:

1. 리포지토리 우측 **[Releases](https://github.com/stickmongus/open-city-cpp/releases)** 페이지로 이동합니다.
2. 최신 버전(**`v0.8.0`**)의 **`OpenCity-Windows-x64.zip`** 파일을 다운로드하고 압축을 풉니다.
3. **`open_city.exe`** 를 더블클릭하면 바로 게임이 시작됩니다!

## 주요 기능 (v0.8.0 업데이트)

* **`[K]` 통합 4탭 커스텀 스튜디오 (`캐릭터 · 총기 건스미스 · 차량 풀 커스텀 · 조준선/HUD`)**
  * **캐릭터 스튜디오 (`Tab 1`)**: 3D 헤어·헤드기어 7종(숏컷·포마드·모호크·스냅백·**피해 `-8%` 풀페이스 헬멧**·사이버 바이저·**24K VIP 골드 크라운**), 헤어 컬러 6종, 아이웨어 4종, 피부 톤 5종(1인칭 손·팔 동시 반영), 상의 9종·하의 7종 커스텀 컬러, 3D 등 액세서리 4종(백팩·더플백·사이버 윙팩)
  * **총기 건스미스 (`Tab 2`)**: 무기별 메탈릭·골드·크롬·사이버네온 스킨 6종, **전술 소음기**(전용 소음 총성·탄퍼짐 `-15%`·**경찰 수배열기 약 `-80%` 은밀 사격**), **대용량 확장 탄창**(`+50%` 장탄수 & 3D 대형 탄창), **3D 실시간 레이저 사이트**(`Red/Green/Cyan`, 지향사격 집탄 `+30%`), 예광탄 컬러 6종, **1인칭 도트·저격 스코프 색상 5종**
  * **차량 풀 커스텀 (`Tab 3`, 개인 차고 자동 저장)**: **미러 실버 크롬·24K 골드 크롬** 포함 12종 도색, 듀얼 GT 레이싱 스트라이프 5종, 단조 휠 5종, **스완넥 타임어택 대형 윙**(`코너링 그립 +6%`), **서스펜션 차고·슬램드 마이너스 캠버(`-8.5°`) 4단계**, 제논/컬러 헤드라이트 5종, LED 네온 언더글로우 6종, **컬러 드리프트 연기 6종**
  * **조준선 & HUD 커스텀 (`Tab 4`)**: 조준선 스타일 4종(십자·핀포인트·서클·쉐브론) × 컬러 6종 × 크기 3단계 × 외곽선 토글, `KM/H` ↔ `MPH` 속도계, HUD 테마 컬러 4종
* **총기·중화기 11종 풀 아스날 & 3.2배율 광학 저격 스코프 (`1인칭·3인칭 3D 모델 + 전용 사운드`)**
  * `맨주먹`, `9mm 권총`, `전술 기관단총`, `펌프 샷건`, `돌격 카빈소총`, `컴뱃 중기관총`, `전술 폭발 런처`, **`44 매그넘 리볼버`**, **`전자동 드럼 샷건`**, **`전술 저격소총`**(`3.2x` 광학 스코프·거리계), **`6열 회전 개틀링 미니건`**
* **32-스테이션 곡면 스컬프팅 3D 차량 16종 풀 라인업 (`전시장 10종 + 긴급·특수차량`)**

| 입력 | 동작 |

## 소스 코드에서 직접 빌드하기 (CMake + C++20)

`raylib 5.5`는 CMake `FetchContent`를 통해 자동으로 다운로드·정적 링크됩니다.

### Windows (Visual Studio 2022 + CMake)
```powershell
cmake -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release --parallel
.\build\Release\open_city.exe
```

### Linux (Debian / Ubuntu)
```bash
sudo apt-get install build-essential cmake ninja-build \
  libgl1-mesa-dev libx11-dev libxrandr-dev libxi-dev libxcursor-dev libxinerama-dev
cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
ctest --test-dir build --output-on-failure
./build/open_city
```
